# Megatron-LM teaching deck

An English, 16:9 browser presentation for explaining *Megatron-LM: Training Multi-Billion Parameter Language Models Using Model Parallelism*.

- Slides 1–8 preserve the current PowerPoint pages.
- Slides 9–18 use input-driven teaching simulations and retain relevant original paper evidence.
- Slides 19–23 are optional Q&A appendices with inspectable toy calculations and original tables.
- Use the page arrows or keyboard arrow keys to navigate.
- Change the controls on each lab page to see a computed value, mechanism, or evidence comparison update. The whole-layer recap has reset, phase-step, play/pause, and scrub controls.
- Click a paper figure to enlarge it.

The former preset Q&A slide has been removed. See [REDESIGN_PLAN.md](REDESIGN_PLAN.md) for the teaching contract, page-by-page interactions, and the GitHub teaching demos that informed the redesign.

The original paper figures are reproduced for academic presentation and attributed on the slides.
